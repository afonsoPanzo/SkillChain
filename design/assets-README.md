# Assets

- avatar-*.svg — layered avatar. Layers are grouped by id (#turbo-goggles, #frame-devnet, #frame-validator) so they can be split into separate React components. Hue in code is derived from the wallet address: hue = hash(address) % 360 (see hueOf() in the prototype); bg hsl(h 42% 30%), head hsl(h 55% 66%), body hsl(h 45% 18%).
- icon-heart.svg — quiz life. Empty state fill #2A2E3B.
- Fonts (Google Fonts): Bricolage Grotesque 400–800, JetBrains Mono 400–600.
